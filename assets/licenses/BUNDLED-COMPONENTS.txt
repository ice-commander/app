Ice Commander — bundled third-party components
==============================================

Ice Commander itself is licensed under MIT OR Apache-2.0; see LICENSE-MIT and
LICENSE-APACHE-2.0 in this directory.

This file lists the third-party libraries shipped alongside the application, the exact
version of each, and where its corresponding source can be obtained. It exists so that the
LGPL and GPL requirements on source availability are met.

Linux packages (.deb / .rpm / Arch) bundle none of the libraries below; GTK and everything
else comes from the distribution.

fakelzo (in place of lzo2) — MIT                                    Windows, macOS
    NO GPL CODE IS SHIPPED IN EITHER BUNDLE. The file named liblzo2.2.dylib (macOS) or
    liblzo2-2.dll (Windows) is NOT Oberhumer's LZO, which is GPL-2.0-or-later. It is
    src/fakelzo/fakelzo.c — 40 lines of our own MIT-licensed code exporting the only two
    symbols libcairo-script-interpreter imports (lzo2a_decompress, lzo2a_999_compress),
    which report failure instead of compressing. No LZO code was used or consulted; only
    the two function signatures are shared, and signatures are not copyrightable.

    Why it exists at all: the real library reaches the bundle through a chain of optional
    dependencies nobody asked for —

        libgtk-4 -> libcairo-script-interpreter -> liblzo2

    and the loader requires it to be present because the interpreter links it. Nothing in
    the application reaches that code. Measured, not assumed: a build with an instrumented
    stand-in logged ZERO calls across a full session — both panels, image and PDF preview,
    video playback, the editor, settings and the terminal.

    macOS:   builder/osx.sh overwrites the copy dylibbundler pulled in, before signing.
    Windows: src/gtk-app/setup.nsi excludes liblzo2-2.dll from the artifacts tree with
             `File /r /x` and packs ours instead — so the GPL library is never placed in
             the installer archive, which is what matters for distribution.

    Consequence: cairo-script serialisation, a GTK debugging facility, does not work in
    these builds. Nothing the application offers depends on it.

    Source:   src/fakelzo/ in this repository, with build scripts for both platforms
              and a README covering the reasoning and the measurement.

    The Ice Commander source tree itself remains MIT OR Apache-2.0, and the Linux build
    contains no GPL code either.


FreeType — FTL                                                      Windows, macOS
    Font rasteriser, pulled in by Pango and the GTK stack. FreeType is dual-licensed
    "FTL or GPL-2.0"; this project uses it under the FTL, which asks that its use be
    credited in the documentation — this entry and FreeType-FTL.txt are that credit.

    Version:  2.14.3 (macOS, Homebrew) / 2.14.1 (Windows, MSYS2)
    Source:   https://gitlab.freedesktop.org/freetype/freetype
    License:  FreeType-FTL.txt


gdk-pixbuf's macOS-icon loader — LGPL, despite the string saying "GPL"          Windows
    Not a separate file: part of libgdk_pixbuf-2.0-0.dll. Noted here because every licence
    scanner finds it.

    The library reports "GPL" for that one format and "LGPL" for the other fourteen. The
    licence is LGPL, stated in the header of the source file itself, unchanged since the
    file was added in 2007:

      "This library is free software; you can redistribute it and/or modify it under the
       terms of the GNU Lesser General Public License ... version 2 of the License, or
       (at your option) any later version."

      https://gitlab.gnome.org/GNOME/gdk-pixbuf/-/blob/2.44.4/gdk-pixbuf/io-icns.c#L6-17

    The "GPL" on line 521 of that same file fills a display field returned by
    gdk_pixbuf_format_get_license(). It contradicts the file's own header, gdk-pixbuf's
    COPYING (LGPL-2.1) and Debian's copyright file, which puts GPL-2+ only on tests/* and
    thumbnailer/*. An upstream typo, not a licence.

      https://gitlab.gnome.org/GNOME/gdk-pixbuf/-/blob/2.44.4/gdk-pixbuf/io-icns.c#L521

Rust dependencies
    Every Rust crate compiled into the binaries is listed with its license in
    THIRD-PARTY-LICENSES.md in the source repository.


Obtaining source
    For any component above, the linked upstream repository at the stated version is the
    corresponding source. For the MSYS2 builds, the package page on packages.msys2.org
    links both the upstream release and the MSYS2 build recipe. If you need a copy we can
    provide directly, write to support@icecommander.com.
